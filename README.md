# Conference Presentations

A public directory for Micah Miner's conference presentations, keynotes,
workshops, webinars, doctoral milestones, course presentations, and alternate
editions.

The site organizes the presentations as an evolving public argument rather than
a collection of unrelated slide decks. Visitors can search the full directory,
filter by audience and format, or use the audience pathways to see how shared
ideas adapt across practitioner, scholarly, civic, and district-leadership
settings.

## Directory scope

The directory includes every currently identified public, presentation-formatted
route in the `minerclass` GitHub account. Companion articles, dashboards, games,
research studios, and training modules remain linked from their subject hubs so
the presentation directory stays usable.

Each listing identifies its audience, format, event or course context, and
public status. Event editions remain available as archives even when a newer
version of the argument exists.

## Accessible filtering

- Search uses the visible title, event, topic, audience, and format text.
- Audience and format filters can be combined.
- The result count is announced as a live status message.
- All controls use native form elements and work from the keyboard.
- The clear button restores all 20 presentations and returns focus to search.
- The skip link moves directly to the directory.

Open `index.html` directly in a browser or serve the folder with any simple static web server.

## Publish

This site is designed for GitHub Pages and requires no build step or external dependencies.

## Privacy

The repository contains only public presentation links and public professional information. It contains no participant, student, staff, or research-subject data.
